# Oral_Cancer_Data_Analysis
Overview
This repository contains a data analysis and prediction model for oral cancer using structured datasets and SQL queries. The goal is to explore the data, identify key risk factors, and develop insights that can assist in early detection and prevention.

Files in This Repository
📂 Oral_cancer_Prediction.xlsx – Contains the raw dataset with patient details, risk factors (e.g., tobacco, alcohol), and diagnosis outcomes.

📂 Oral_cancer_data_analysis.sql – SQL scripts for data preprocessing, statistical analysis, and trend identification.

Data Analysis Process
Data Cleaning: Handling missing values, duplicates, and inconsistencies.
Exploratory Data Analysis (EDA): Identifying trends, correlations, and key risk factors.
Statistical Insights: Using SQL queries for survival rates, tobacco/alcohol impact, and age-wise distribution.
Prediction Modeling (Future Scope): Building a machine learning model based on risk indicators.

Key Insights
📌 Correlation Analysis: Relationship between tobacco, alcohol, and oral cancer cases.
📌 Survival Rate Analysis: Identifying treatment effectiveness and patient survival statistics.
📌 High-Risk Factors: Determining key contributors to oral cancer.

How to Use This Repository
